# Grifindo Toys Management System 🎮

This is a C# desktop application developed for Grifindo Toys to manage toy inventory, employee records, and sales transactions. Built using Windows Forms in Visual Studio.

## 💡 Features
- Add/Edit/Delete toys
- Track sales and stock levels
- Employee management module
- Simple UI for non-technical users

## 🛠️ Tech Stack
- C#
- .NET Framework
- Windows Forms
- SQL Server (optional, if used)

## 📂 How to Run
1. Open `GrifindoToys.sln` in Visual Studio
2. Build and run the solution
3. Use the app to manage toy data
